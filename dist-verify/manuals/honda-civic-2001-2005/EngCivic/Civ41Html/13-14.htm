Transmission Installation (cont'd)

 13-14  

  1. Install the water pipe bolt (A), then connect the back-up light switch connector (B).

  1. Apply Urea Grease UM264 (P/N 41211-PY5-305) to the end of the slave cylinder rod. Install the slave cylinder. Take care not to bend the clutch line.

  1. Install the battery tray (A), then connect the ground cable (B).

  1. Install the air cleaner housing (see step 33 on page 5-15).
  1. Install the intake air duct (see step 6 on page 5-2).
  1. Install the battery. Connect the positive (+) cable first, then the negative (-) cable to the battery.
  1. Refill the transmission fluid (see page 13-4).
  1. Test-drive the vehicle.
  1. Check the clutch operation.
  1. Check the front wheel alignment, refer to the 2001 Civic Shop Manual on this CD (see page 18-4).
  1. Enter the anti-theft code for the radio, then enter the customer's radio station presets.
