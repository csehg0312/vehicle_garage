Cylinder Head

Valves, Springs, Split Collars, Tappets and Adjust Shims Installation

 6-26  

Special Tools Required

  • Installer valve stem seal 5-8840-9050-0
  • Adapter valve spring 5-8840-7003-0

Valve Stem Oil Seal Installation

  1. Install the value spring lower seat.
  1. Apply a coat engine oil to the oil seal inner face.
  1. Use an oil seal installer (5-8840-9050-0) to install the oil seal to the valve guide.

Intake and Exhaust Valve Installation

  1. Apply a coat of engine oil to valve stem.
  1. Install the intake and exhaust valves.
  1. Turn the cylinder head up to install the valve springs. Take care not to allow the installed valves to fall down.

Valve Spring Installation

  1. Turn the cylinder head up to install the valve springs. Take care not to allow the installed valves to fall free.

Split Collar Installation

  1. Use the spring compressor with adapter (5-8840-7003-0) to push the valve spring into position.
  1. Install the split collar to the valve stem.
  1. Set the split collar by tapping around the bead of the collar with a rubber hammer.

Tappet and Shim Installation

  1. Apply engine oil to tappet (A) and shim (B), then install tappet and shim.
