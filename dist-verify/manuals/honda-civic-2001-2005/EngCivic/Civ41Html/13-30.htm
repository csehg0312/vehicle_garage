Input Shaft Bearing and Oil Seal Replacement (cont'd)

 13-30

Output Shaft Bearing Replacement

  1. Install the needle bearing (A) using the special tool with a press.

    NOTE: Do not use a hammer to install the needle bearing.

Special Tools Required

  • Puller bridge 5-8840-0183-0 (J-33367)
  • Axle shaft oil seal remover 5-8840-0027-0 (J-26941)
  • Bearing outer race installer 5-8840-0006-0 (J-7817)

  1. Remove the bearing outer races (A) using the special tools.

  1. Install the bearing outer race (A) using the special tool with a hammer.
