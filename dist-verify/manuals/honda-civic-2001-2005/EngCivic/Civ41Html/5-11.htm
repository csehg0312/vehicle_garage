Engine Assembly

Engine Installation (cont'd)

 5-11  

  1. Lower the hoist.
  1. Install the upper bracket (A), then tighten the bolt/nut in the numbered sequence shown.

  1. Install the ground cable (B).
  1. Tighten the support bolt and nuts.

  1. Remove the chain hoist from the engine.
  1. Raise the hoist to full height.
  1. Install a new spring clip on the end of each driveshaft, then install the driveshafts. Make sure each clip ''clicks'' into place in the differential and intermediate shaft.
  1. Connect the suspension lower arm ball joints, refer to the '01 Civic Shop Manual on this CD (see step 3 on page 18-19).
  1. Connect the stabiliser links, refer to the '01 Civic Shop Manual on this CD (see page 18-18).
  1. Install the exhaust pipe A/three way catalytic converter (TWC) assembly (A); use new gaskets (B) and new self locking nuts (C).
