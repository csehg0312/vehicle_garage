Transmission Installation

 13-10  

  1. Install the release lever and release bearing (see page 12-12).
  1. Check the two dowel pins (A) are installed in the clutch housing.

  1. Install the extension plate (B).
  1. Place the transmission (C) on the transmission jack and raise it to the engine level.
  1. Install the transmission mounting bolts.

  1. Install the transmission rear mount (B).

  1. Install the front engine mount.
