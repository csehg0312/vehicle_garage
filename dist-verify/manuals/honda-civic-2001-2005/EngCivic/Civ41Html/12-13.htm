Clutch Shaft Bearing Replacement

  1. If Clutch shaft or Clutch shaft bearing need replacement, remove components as follows.
  1. Remove the bolts holding the clutch lever. Slide the lever toward the input shaft.
  1. Drive outer clutch shaft needle bearing (A) towards the outside of clutch housing, using the special tool.

  1. Remove the clutch shaft (B).
  1. Remove the inner clutch shaft seal (C).
  1. Remove the inner clutch shaft needle bearing (A) using the special tool. Position the puller legs under the bearing and thread the rod down to expand legs. Hold rod while tightening nut to remove the bearing.

  1. Install the new inner clutch shaft needle bearing (A) into the clutch housing (B) using the special tool.

    NOTE:

  • If the clutch shaft, bearing and seals have been removed, install as follows.
  • Before installing, apply grease to both the inside and outside of bearing.

  1. Install the new shaft seal (A).

  1. Install the clutch shaft (B).
  1. Install the new outer clutch shaft needle bearing (C) using the special tool. Drive bushing inward until line on tool is flush with housing.
  1. Install the clutch release bearing refer to page 12-12.
  1. Secure the clutch lever to the clutch shaft.
