Engine Installation (cont'd)

 5-14

A/T:
  1. Tighten the front mount mounting bolt.

  1. Remove the chain hoist from the engine.
  2. Raise the hoist to full height.
  3. Install a new spring clip on the end of each driveshaft, then install the driveshafts. Make sure each clip ''clicks'' into place in the differential and intermediate shaft.
  4. Connect the suspension lower arm ball joints and stabiliser links, refer to the '01 Civic Shop Manual on this CD (see page 18-18).
  5. Install the shift control cable (A), then install the shift cable covers (B) (A/T).
