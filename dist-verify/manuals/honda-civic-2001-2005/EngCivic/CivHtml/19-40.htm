Conventional Brake Components

Rear Brake Shoes Replacement (cont'd)

 19-40  

  1. Install the tension pins (A) and the retainer springs (B) by pushing in on each spring and turning each pin.

  1. Install the lower return spring.
  2. Install the brake drum and rear wheel.
  3. If the wheel cylinder has been removed, bleed the brake system (see page 19-7).
  4. Press the brake pedal several times to set the self-adjusting brake.
  5. Adjust the parking brake (see page 19-5).

 Removal/Disassembly (5-door)
  1. Remove the brake drum (see page 18-24).
  2. Unhook the upper return spring (A) from the rearward shoe using a tool (B).

  1. Remove the tension pins (A) by pushing each retainer spring (B) and turning the pins.
