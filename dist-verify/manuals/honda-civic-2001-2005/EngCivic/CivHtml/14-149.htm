Shift Cable Replacement (cont'd)

  1. Remove the shift cable covers (A), then remove the bolts securing the shift cable holder (B).

  1. Remove the lock bolt securing the control lever (C), then remove the shift cable (D) with the control lever from the control shaft (E).
  2. Insert the new shift cable through the grommet hole.
  3. Install the shift cable guide bracket on the shift cable, then install the shift cable guide bracket to the body.
  4. Verify that the transmission is in position on the control shaft.
  5. Install the control lever with the shift cable on the control shaft. Do not bend the shift cable excessively.
  6. Secure the shift cable holder with the bolts on the transmission.
  7. Install the lock bolt with a new lock washer (F), then bend the lock washer tab against the bolt head.
  8. Install the shift cable covers.
