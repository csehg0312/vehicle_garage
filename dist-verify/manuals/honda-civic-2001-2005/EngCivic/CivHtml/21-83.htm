Evaporator Temperature Sensor Replacement

 21-83  

4-door

NOTE: LHD type is shown, RHD type is symmetrical.

  1. Disconnect the 2P connector (A) from the evaporator temperature sensor (B), then remove the connector clip (C). Turn the evaporator temperature sensor counter-clockwise to the stop and carefully pull out it.

  1. Install the sensor in the reverse order of removal.

 5-door KE Model
  1. Disconnect the 2P connector (A) from the evaporator temperature sensor (B), then remove the connector clip (C). Remove the self-tapping screw and carefully pull out the evaporator temperature.

  1. Install the sensor in the reverse order of removal.
