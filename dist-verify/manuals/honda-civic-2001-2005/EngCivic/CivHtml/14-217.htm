Valve Body

Valve Bodies and ATF Strainer Installation (cont'd)

 14-217  

  1. Tighten the five bolts on the main valve body to 12 Nm (1.2 kgf/m, 8.7 lbf/ft).
  1. Make sure the ATF pump drive gear and ATF pump driven gear shaft move smoothly. If they don't move smoothly, disassemble the valve bodies and loosen the main valve body bolts.
    Realign the ATF pump driven gear shaft, reassemble the valve bodies and retighten the bolts to the specified torque, then recheck.
    Failure to align the ATF pump driven gear shaft correctly will result in a seized ATF pump drive gear or ATF pump driven gear shaft.

  2. Install the stator shaft and stator shaft stop.
  3. Install the three bolts and stop shaft bracket on the secondary valve body.
  4. Install the torque converter check valve, valve spring, cooler relief valve and valve spring in the regulator valve body, then install the regulator valve body with two dowel pins on the main valve body (one bolt).
  5. Install the lock-up separator plate and two dowel pins on the regulator valve body.
  6. Install the lock-up valve body (seven bolts).
  7. Install the four ATF feed pipes in the servo body.
  8. Install the three ATF feed pipes in the secondary valve body; install the 105.8 mm feed pipe with its filter side away from the secondary valve body.
  9. Install the two ATF feed pipes in the main valve body; install the 138.8 mm feed pipe with its filter side away from the main valve body.
  10. Install the 220 mm ATF feed pipe in the main valve body and the ATF feed pipe in the lock-up valve body (7-position).
