Power Steering

Steering Gearbox Overhaul (cont'd)

 17-54  

  1. Grease the sliding surface of the rack guide (A), and install it onto the gearbox housing.

  1. Apply sealant all around the threads on the rack guide screw (B), then install the spring (C), rack guide screw and locknut (D). Adjust the rack guide screw (see page 17-13). After adjusting, check that the rack moves smoothly by sliding it right and left.
  1. Install the rack end plug (A).

  1. Clean off any grease or contamination from the boot installation grooves (C) around on the housing.
  2. Install boot B, and set the boot end in the installation grooves in the cylinder housing and rack end plug properly.
  3. Install the clip (D) and boot guard (E).
  4. Install the new boot band (F) in the band grooves of boot B by aligning the tabs (G) with the holes (H) in the band.
