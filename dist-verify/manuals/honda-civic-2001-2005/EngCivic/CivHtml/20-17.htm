Rear Door Outer Handle Replacement (cont'd)

 20-17  

  1. Remove the screws securing the latch (A), then move the latch down. Take care not to bend any of the rods.

    Fastener Locations
    : Screw, 3

  1. Remove the nuts securing the outer handle (A) and outer handle protector (B) (for some models).
    Fastener Locations
    : Nut, 2

  1. For some models: Remove the outer handle protector (A) from the outer handle (B).

  1. Pull out the outer handle (A) in the numbered sequence, then remove it.

  1. Install the handle in the reverse order of removal, and note these items:
  • Make sure each rod is connected securely.
  • Make sure the door locks and opens properly.
