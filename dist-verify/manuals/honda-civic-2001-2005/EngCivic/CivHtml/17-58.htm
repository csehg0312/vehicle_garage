Power Steering

Steering Gearbox Installation (cont'd)

 17-58  

  1. Install the steering rack guard (A).

  1. Install the engine wire harness (B) on the harness bracket (C).
  2. Under the steering gearbox, install the return hose clamp (A) on the gearbox.
  1. Above the steering gearbox, connect the feed line (A) securely, and tighten the 14 mm flare nut (B).

  1. Connect the return line (C) securely, and tighten the 16 mm flare nut (D).
  2. Install the feed line clamp (A) on the gearbox. Make sure that there is no interference between the feed and return lines with any other parts.
