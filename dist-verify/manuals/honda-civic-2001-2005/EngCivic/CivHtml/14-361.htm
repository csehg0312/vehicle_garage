Transmission Housing/Flywheel Housing

Flywheel Housing Input Shaft Oil Seal Replacement

 14-361

Control Shaft Assembly Removal/Installation

Special Tools Required
  • Handle driver, 07749-0010000
  • Driver attachment, 32 x 35 mm, 07746-0010100
  1. Remove the input shaft oil seal (A) from the flywheel housing (B).

  1. Install the oil seal (A) in the flywheel housing (B) with the special tools.
  1. Remove the bolt (A) and lock washer (B).

  1. Remove the control lever (C) from the control shaft (D).
  2. Remove the control shaft assembly from the transmission housing (E).
  3. Install the control shaft assembly in the transmission housing.
  4. Install the control lever to the control shaft.
  5. Install and tighten the bolt with the new lock washer.
