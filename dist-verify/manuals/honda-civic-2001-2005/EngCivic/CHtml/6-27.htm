Cylinder Head Installation (cont'd)

 6-27  

  1. Install the A/C hose bracket (A) and P/S hose bracket (B).

  1. Loosely install the alternator.
  2. Adjust the alternator belt tension, refer to the '01 Civic Shop Manual on this CD (see page 4-38) or the alternator-compressor belt tension, refer to the '01 Civic Shop Manual on this CD (see page 4-37).
  3. Loosely install the P/S pump belt and pump.
  4. Adjust the P/S pump belt, refer to the '01 Civic Shop Manual on this CD (see page 17-23).
  5. Install the connecting pipe (A) with a new O-ring (B).
  1. Install the ground cable (A), upper radiator hose (B), lower radiator hose (C), heater hose (D) and water bypass hose (E).

  1. Install the EVAP canister hose.
