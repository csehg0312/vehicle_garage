Starting System

Starter Replacement

 4-8  

  1. Make sure you have the anti-theft code for the radio, then write down the frequencies for the radio's preset buttons.
  2. Disconnect the battery negative cable, then disconnect the positive cable.
  3. Disconnect the knock sensor connector.
  4. Remove the bolt (A) securing the harness bracket, then remove the intake manifold brackets (B).
  1. Disconnect the starter cable (A) from the B terminal on the solenoid, then disconnect the BLK/WHT wire (B) from the S terminal.

  1. Remove the two bolts holding the starter, then remove the starter.
  2. Install the starter in the reverse order of removal. Make sure the crimped side of the ring terminal (A) is facing out.

  1. Connect the battery positive cable and negative cable to the battery.
  2. Enter the anti-theft code for the radio, then enter the customer's radio station presets.
