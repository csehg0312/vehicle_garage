 Wire Colour Terminal Name Description Signal Condition

93 RED/BLU Manifold absolute pressure (MAP) sensor supply Provides MAP sensor About 5 V with the ignition switch ON (II)
94 YEL/RED Manifold absolute pressure (MAP) sensor signal Detects MAP sensor signal About 2 V with the ignition switch ON (II)

About 2 V with the engine running at idle
95 BLK/YEL Manifold absolute pressure (MAP) sensor ground Ground for the MAP sensor 0 V at all times
97 WHT/RED Mass air flow (MAF) sensor supply Provides MAF sensor About 5 V with the ignition switch ON (II)

NOTICE

  • In case you measure the standard voltage of ECM, remove a connector and use the Test pin box and Test harness.
