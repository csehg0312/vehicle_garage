Input Shaft Disassembly

 13-20

Input Shaft Inspection

Special Tools Required

  • Bearing remover 5-8840-0015-0 (J-22912-01)

  1. Remove the input shaft bearing (A) using the special tool with a press.

  1. Remove the input 3rd gear, 3rd gear needle bearing, 3rd block ring, 3rd/4th synchroniser assembly, 4th block ring, input 4th gear, 4th gear needle bearing, 4th gear needle bearing collar, 4th gear thrust washer and rear input shaft bearing.

    NOTE: Remove all of above parts together using the special tool and a press.

  1. Remove the input shaft.

  1. Measure the run-out of the input shaft and replace with a new one if reading exceeds limit.

    Limit: 0.02 mm (0.0008 in.)
