M/T Differential

Carrier Replacement (cont'd)

 13-40  

  1. Measure the differential case diameter (Drive shaft).

Limit:

30.10 mm (1.1850 in.)

  1. Install the differential case.
  1. Apply oil to the cross pin, differential gears, thrust portion, side gear shaft portion and side gear spline portion before installation.
  1. Install the side gears and thrust washers.
  1. Install the 2 side gears to the differential case together with the thrust washers. Next, position two thrust washers and pinion gears opposite each other. Install them in their positions by turning the side gear.
  1. Install the cross pin by aligning it with the lock pin hole in the differential case.
  1. Install the lock pin (A) using pin punch. Stake portion (B) of lock pin hole in the differential case with a punch to prevent removal of lock pin.

    NOTE:

Drive the lock pin deep enough so that it bottoms against the differential case.

  1. Heat the speedometer drive gear to approximately 90°C (194°F) and install the speedometer drive gear.

NOTE:

  • If the speedometer drive gear is removed, install a new one.
  • When heating the speedometer drive gear, never use hot water. Use an oil heater or hair dryer.

  1. Install the side bearing (A) using the special tools.
