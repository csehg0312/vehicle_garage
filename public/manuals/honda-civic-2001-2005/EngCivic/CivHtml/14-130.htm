Automatic Transmission

Transmission Installation

 14-130  

  1. Install the starter (A) on the torque converter housing (B).

  1. Install the torque converter assembly (C) on the mainshaft (D) with a new O-ring (E).
  2. Install the 14 mm dowel pins (F) in the torque converter housing.
  3. Place the transmission on a jack and raise it to the engine level.
  4. Attach the transmission to the engine, then install the rear mount/bracket (A) with the mount/bracket bolts (B) and the transmission housing mounting bolt (C).
