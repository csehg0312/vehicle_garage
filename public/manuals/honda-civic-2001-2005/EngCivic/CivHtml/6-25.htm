Timing Belt Installation (cont'd)

 6-25  

  1. Install the upper cover (A), then connect the TDC sensor connector (B) and install the grommet (C).

  1. Install the upper bracket (A), then tighten the nuts in the numbered sequence shown.
  1. Install the cylinder head cover (see page 6-55).
  2. Install the harness holder (A) and throttle cable clamps (B).

  1. Loosely install the alternator.
  2. Adjust the alternator belt tension (see page 4-38) or the alternator-compressor belt tension (see page 4-37).
  3. Loosely install the P/S pump belt and pump.
  4. Adjust the P/S pump belt (see page 17-23).
  5. Install the splash shield.
  6. Install the front tyres/wheels.
  7. Clean the battery posts and cable terminals with sandpaper, then assemble them and apply grease to prevent corrosion.
  8. Enter the anti-theft code for the radio, then enter the customer's radio station presets.
