  2. Insert the new shift cable through the grommet hole, then install the shift cable guide bracket.

  4. Install the control lever with the shift cable on the control shaft. Do not bend the shift cable excessively.
  5. Secure the shift cable holder with the bolts on the transmission.
  6. Install the lock bolt with a new lock washer (F), then bend the lock washer tab against the bolt head.
  7. Install the shift cable covers.
