Heating

Heater Control Panel Removal and Installation

 21-51  

4-door, 5-door KE Model

NOTE: LHD type is shown, RHD type is symmetrical.

  1. Remove the centre panel (see page 20-78).
  2. Remove the dials (A), then remove the self-tapping screws and the heater control panel (B) from the centre panel (C).

  1. Install the control panel in the reverse order of removal. After installation, operate the control panel controls to see whether it works properly.
  2. Run the self-diagnosis function to confirm that there are no problems in the system (see page 21-5).

 Except 4-door, 5-door KE Model
  1. Remove the centre panel (see page 20-219).
  2. Remove the self-tapping screws and the heater control panel (A) from the centre panel (B).

  1. Install the control panel in the reverse order of removal. After installation, operate the control panel controls to see whether it works properly.
