Rear Door Latch Replacement

  1. If equipped, release the hook (A), then remove the outer handle protector (B) from the outer handle (C).

  1. Pull out the outer handle (A), then remove it.

  1. Install the handle in the reverse order of removal and make sure the door locks and opens properly.
