Wiper/Washers

Rear Window Wiper Intermittent Control Unit Input Test (cont'd)

 22-175  

  1. With the connector still disconnected, make these input tests at the connectors.
  • If any test indicates a problem, find and correct the cause, then recheck the system.
  • If all the input tests prove OK, the control unit must be faulty; replace it.
