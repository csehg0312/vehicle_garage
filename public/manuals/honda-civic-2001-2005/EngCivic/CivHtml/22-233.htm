Keyless/Power Door Lock System

Control Unit Input Test - With Super Locking (cont'd)

 22-233  

  1. Reconnect all connector to the under-dash fuse/relay box and make sure these input tests at the appropriate connectors on the under-dash fuse/relay box
  • If any test indicates a problem, find and correct the cause, then recheck the system.
  • If all the input tests prove OK, the multiplex control unit must be faulty, replace the under-dash fuse/relay box assembly.
