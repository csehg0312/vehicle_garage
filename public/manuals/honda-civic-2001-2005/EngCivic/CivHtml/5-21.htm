Engine Assembly

Engine Installation (cont'd)

 5-21  

  1. Install the battery base.
  1. Install the intake air duct (A) and ground cable (B).

  1. Install the battery cable (A) on the under-hood fuse/relay box, then install the harness clamps (B).
  1. Install the intake resonator.

  1. Clean the battery posts and cable terminals with sandpaper, then assemble them and apply grease to prevent corrosion.
  2. Move the shift lever to each gear and verify that the A/T gear position indicator, follows the transmission range switch (A/T, Honda multi matic).
  3. Check that the transmission shifts into gear smoothly (M/T).
  4. Inspect for fuel leaks. Turn ON (II) the ignition switch (do not operate the starter) so that the fuel pump runs for approximately 2 seconds and pressurises the fuel line. Repeat this operation 2 or 3 times, then check for fuel leakage at any point in the fuel line.
  5. Refill the engine with engine oil (see page 8-5).
  6. Refill the transmission with fluid:
  • Manual transmission (see page 13-3).
  • Automatic transmission (see page 14-122).
  • Honda multi matic (see page 14-312).
  1. Refill the radiator with engine coolant, and bleed air from the cooling system with the heater valve open (see page 10-8).
  2. Check the wheel alignment (see page 18-4).
  3. Enter the anti-theft code for the radio, then enter the customer's radio station presets.
