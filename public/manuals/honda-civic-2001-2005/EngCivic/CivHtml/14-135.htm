Automatic Transmission

Transmission Installation (cont'd)

 14-135  

  1. Connect the countershaft speed sensor connector and install the harness clamp on the clamp bracket.

  1. Connect the torque converter clutch solenoid valve connector (A), then install the harness clamp on the transmission hanger.

  1. Install the transmission ground cable (B).
  1. Connect the starter cables (A) to the starter (B) and install the harness clamp on the clamp bracket. Make sure the crimped side of the starter cable ring terminal is facing out.

  1. Install the battery base, then install the harness clamp on the battery base.
  2. Install the resonator and intake air duct.
  3. Refill the transmission with ATF (see page 14-122).
  4. Install the battery tray and battery, then secure the battery with its hold-down bracket.
  5. Connect the battery positive terminal, then connect the negative terminal.
  6. Set the parking brake. Start the engine and shift the transmission through all gears three times.
  7. Check the shift lever operation, A/T gear position indicator operation and shift cable adjustment.
  8. Check and adjust the front wheel alignment (see page 18-4).
  9. Start the engine and let it reach normal operating temperature (the radiator fan comes on) with the transmission in P.gif or N.gif position, then turn if off and check the ATF level (see page 14-121).
  10. Perform a road test (see page 14-108).
  11. Enter the radio station presets and set the clock.
