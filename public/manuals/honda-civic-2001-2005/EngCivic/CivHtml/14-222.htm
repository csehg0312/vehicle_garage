Transmission End Cover

End Cover, 1st Gears and 1st Clutch Installation (cont'd)

 14-222  

  1. Install the old conical spring washer (A) and old locknut (B) on the countershaft (C). Tighten the old locknut to 103 Nm (10.5 kgf/m, 75.9 lbf/ft), then remove the old locknut and conical spring washer.

NOTE:

  • Use a torque wrench to tighten the locknut. Do not use an impact wrench.
  • Countershaft locknut has left-hand threads.

  1. Install the special tool onto the mainshaft.
  1. Install the mainshaft 1st gear collar (A), mainshaft 1st gear (B), needle bearing (C), thrust needle bearing (D) and thrust washer (E) on the mainshaft (F).

  1. Wrap the mainshaft splines with tape to prevent O-ring damage. Install new O-rings (G) in the mainshaft grooves, then remove the tape.
  2. Install the 1st clutch assembly (H) on the mainshaft.
