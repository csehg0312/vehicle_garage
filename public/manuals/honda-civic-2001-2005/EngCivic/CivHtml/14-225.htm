Transmission End Cover

End Cover, 1st Gears and 1st Clutch Installation (cont'd)

 14-225  

  1. Tighten the bolts on the transmission range switch while you continue to hold the position.

Do not move the transmission range switch when tightening the bolts. Remove the feeler gauge.

  1. Connect the switch harness connector securely, then secure the switch harness (A) with the clamps (B).

  1. Install the transmission range switch cover (C).
  1. Install the filter/gasket (A) in A/T clutch pressure control solenoid valve body groove, then install the A/T clutch pressure control solenoid valves A and B (B), if it was removed. Do not pinch the filter/gasket.

  1. Install the ATF cooler lines and new sealing washers. Tighten the line fittings to 28 Nm (2.9 kgf/m, 21 lbf/ft).
  2. Install the ATF dipstick.
