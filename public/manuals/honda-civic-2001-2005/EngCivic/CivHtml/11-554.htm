Secondary HO2S Replacement

Special Tools Required

O2 sensor wrench 07LAA-PT50101

  1. Disconnect the primary HO2S 4P connector (A), then remove the primary HO2S (B).

  1. Install the primary HO2S in the reverse order of removal.

 Special Tools Required

O2 sensor wrench 07LAA-PT50101

  1. Disconnect the secondary HO2S 4P connector (A), then remove the secondary HO2S (B).

  1. Install the secondary HO2S in the reverse order of removal.
