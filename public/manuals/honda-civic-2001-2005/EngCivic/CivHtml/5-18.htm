Engine Installation (cont'd)

 5-18  

  1. Install the A/C compressor (A), then install the alternator lower bracket (B).

  1. Install the A/C hose bracket (A) and P/S hose bracket (B).
  1. Loosely install the alternator.
  2. Adjust the alternator belt tension (see page 4-38) or the alternator-compressor belt tension (see page 4-37).
  3. Loosely install the P/S pump belt and pump.
  4. Adjust the P/S pump belt (see page 17-23).
  5. Push the ECM/PCM connectors through the bulkhead, then install the grommet (A).
