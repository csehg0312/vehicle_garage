Conventional Brake Components

Rear Brake Shoes Replacement (cont'd)

 19-42  

  1. Install the self-adjuster lever (C) and self-adjuster spring (D) on the front side brake shoe (E).

  1. Assemble the brake shoes with the clevis A, adjuster bolt (F), clevis B, upper return spring (G), and lower return spring (H).

NOTE: Fully turn the adjuster bolt into the clevis A.

  1. Apply Molykote 44MA grease onto the sliding surfaces as illustrated. Wipe off any excess. Do not get grease on the brake linings.
Sliding surfaces
O Backside edge of the shoe

  1. Install the shoe assembly on the backing plate fitting the top of the shoes onto the wheel cylinder pistons and the bottom of the shoes onto the locating plate.
  1. Install the tension pins (A), and secure with the retainer springs (B) by pushing it and turning each pin.

  1. Hook the upper return spring (G) with a tool.

  1. Install the brake drum and rear wheel.
  2. If the wheel cylinder has been removed, bleed the brake system (see page 19-7).
  3. Press the brake pedal several times to set the self-adjusting brake.
  4. Adjust the parking brake (see page 19-5).
