Openers

Hood Latch Replacement

 20-266  

  1. If necessary, remove the front bumper (see page 20-243).
  1. If equipped, detach the harness clip (A) and the hood latch switch connector (B) from the body and disconnect it.

  1. Remove the bolts, then remove the hood latch (A) from the body.
    Fastener Location
    : Bolt, 3

  1. Disconnect the hood opener cable (B) from the hood latch. Take care not to bend the cable.
  1. Install the hood latch in the reverse order of removal and note these items:
  • Grease each location of the hood latch indicated by the arrows.
  • Make sure the hood opener cable is connected properly and hood latch switch connector is plugged in properly (for some models).
  • Adjust the hood latch alignment (see page 20-245).
  • Make sure the hood opens properly and locks securely.
