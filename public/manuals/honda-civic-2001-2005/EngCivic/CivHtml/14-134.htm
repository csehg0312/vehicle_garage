Automatic Transmission

Transmission Installation (cont'd)

 14-134  

  1. Install the splash shield.

  1. Connect the connectors to the A/T clutch pressure control solenoid valves A and B, shift solenoid valves A and B (C) and countershaft speed sensor (D), then install the harness clamps on the clamp brackets.
  1. Connect the ATF cooler hoses (A) to the ATF cooler lines (B) (see page 14-136).

  1. Connect the transmission range switch connector (A) and install it on its bracket (B). Install the harness clamp on the clamp bracket.

  1. Install the VSS connector (C), then install the harness clamp on the clamp bracket.
