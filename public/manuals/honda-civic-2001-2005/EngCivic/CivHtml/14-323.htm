Honda Multi Matic Transmission/CVT

CVT Speed Change Control Valve Assembly Replacement

 14-323

CVT Start Clutch Pressure Control Valve Assembly Replacement

  1. Remove the lower valve body assembly (see page 14-321).
  1. Disconnect CVT speed change control valve assembly connector (A) and CVT start clutch pressure control valve assembly connector (B).

  1. Remove the solenoid harness clamp (C).
  2. Remove the seven bolts and remove the CVT speed change control valve assembly (D).
  3. Install the new valve assembly with the CVT start clutch pressure control valve assembly (E) (seven bolts). Replace the CVT start clutch pressure control valve assembly, when replacing the valve assemblies at a same time.
  4. Install the solenoid harness clamp and route the harness in it.
  5. Connect CVT speed change control valve assembly connector and CVT start clutch pressure control valve assembly connector, be sure to connect them correctly.
  6. Install the lower valve body assembly to the transmission (see page 14-322).

 NOTE: If the CVT start clutch pressure control valve assembly and the CVT speed change control valve assembly at a same time, refer to CVT Speed Change Control Valve Assembly Replacement.
  1. Remove the lower valve body assembly (see page 14-321).
  2. Disconnect CVT start clutch pressure control valve assembly connector (A).

  1. Remove the four bolts and remove the CVT start clutch pressure control valve assembly (B).
  2. Install the new valve assembly (four bolts).
  3. Connect CVT start clutch pressure control valve assembly connector.
  4. Install the lower valve body assembly to the transmission (see page 14-322).
