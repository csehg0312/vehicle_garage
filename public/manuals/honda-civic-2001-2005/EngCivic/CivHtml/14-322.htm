Honda Multi Matic Transmission/CVT

Lower Valve Body Assembly Installation

 14-322  

  1. Install the solenoid harness connector (A) with holding the lower valve body assembly (B).

  1. Install the lower valve body assembly (eight bolts).
  2. Install the ATF strainer (C) (two bolts).
  3. Install the ATF pan (D) with the two dowel pins (E) and new gasket (F).
  1. Check the solenoid harness connector for rust, dirt, or oil, then connect the connector securely.
  1. Refill the transmission with ATF (see page 14-320).
  2. Perform the start clutch calibration procedure (see page 14-319).
