Charging System

Alternator Replacement

 4-28  

  1. Make sure you have the anti-theft code for the radio, then write down the frequencies for the radio's preset buttons.
  2. Disconnect the battery negative cable, then disconnect the positive cable.
  3. Remove the front bumper, refer to the 2001 Civic Shop Manual Supplement, P/N 62S5A21 (see page 20-8).
  4. Remove the right side head light, refer to the 2001 Civic Shop Manual (see page 22-114).
  5. Remove the reserve tank.

  1. Remove the drive belt (see page 4-25).
  2. Remove the three bolts securing the alternator.
  1. Disconnect the alternator connector (A) and BLK wire (B) from the alternator.

  1. Remove the alternator.
  2. Install the alternator and drive belt in the reverse order of removal.
  3. Connect the battery positive cable and negative cable to the battery.
  4. Enter the anti-theft code for the radio, then enter the customer's radio station presets.
