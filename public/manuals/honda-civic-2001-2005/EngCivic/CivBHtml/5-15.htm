Materials and Tools

5-15  

SEALER

Use urethane sealer.

  • 3m #08892 (internal)
  • 3m #08893 (external)

or equivalents.

TOOLS

  • Cartridge type
  • Tube type

  • Sealing gun

UNDERCOAT

To be applied to under-floor and wheelhouse.

  • Nox-rust 409-20S
  • Solton 1000S

or equivalent.

ANTI-RUST AGENT

To be applied to weld joints inside the body panel.

  • Rustop
  • Deox #100
  • Waxoyl

or equivalent.

SPRAY GUNS

Use the correct gun toe the agent being used.

Use of a pressure type spray gun is recommended when work involves a considerable number of vehicles.

  • For nox-rust 409-20S/solton 1000S

  • For rustop

  • For deox #100

  • For waxoyl
