Front Wheelhouse/Damper Housing

Installation

 3-41  

  1. Set the new damper housing assembly, front wheelhouse and front bulkhead into position and measure the front compartment diagonally.
    Check the body dimensions (see section 4).
  2. Tack weld the clamped position.
  3. Temporarily install the front sub-frame and check the front side frame position.
  4. Temporarily install the hood, front fender, headlight and front bumper, and check for differences in level and clearance. Make sure the lines flow smoothly.
  5. Perform the main welding:
  • Weld the damper housing and front side frame.
  • Weld the front damper extension and dashboard upper side member.

  2. DASHBOARD UPPER SIDE MEMBER
  3. FRONT SIDE FRAME
  4. DAMPER HOUSING
